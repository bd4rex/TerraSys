# TerraSys brand assets

- `terrasys-logo-original.png`: project-owner supplied source artwork, archived without modification.
- `terrasys-logo-banner.png`: tightly cropped wordmark used by the GitHub README files.
- `terrasys-mark.png`: icon-only crop used by the map sidebar and as the source for application-icon variants.
- `terrasys-app-icon.png`: white rounded-square application icon used by touch icons and dark application headers.
- `terrasys-favicon.svg`: simplified dark-blue, white-T, green-mountain micro mark for modern browsers.
- `terrasys-favicon-16.png`, `terrasys-favicon-32.png`, `terrasys-favicon-48.png`: pixel-sized favicon fallbacks.
- `terrasys-favicon.ico`: multi-size 16/32/48 favicon fallback.

The derived PNG files preserve the source artwork. They are crops and size variants, not redraws.
