## 关键经验

- MapLibre 是渲染器，不是完整地图产品。
- 地图体验由样式、图例、控件、信息密度和 I/O 共同决定。
- 多源重复完整专业样式会降低性能；默认浏览应优先熟悉度与速度。
- PMTiles + nginx 是轻量可移植路径，OSM Carto 提供熟悉视觉，二者可以并存。
- PostGIS + FastAPI + Martin 适合作为个人数据边界。
- GitHub 应保存可重现系统，而不是大型派生地图或私人资料。
