TerraSys 可以学习信息架构、工作流和运维经验，但不复制 OsmAnd 的布局、UI 代码或受保护视觉资产。TerraSys 使用自有桌面布局、Lucide 图标、术语和实现。

## TerraSys 采用的模式

- 分开“可获取、本地、可更新”。
- 按全球、洲、国家和独立区域组织下载单元。
- 保持低缩放全球概览，在未安装范围提供临时在线查看或精确离线包。
- 分开设备容量和应用管理容量。
- 把取消、重试、阶段、队列、耗时和速率附着到对应资源。
- 立即显示缓存盘点并后台刷新；维护状态与资源扫描相互独立。
- 按类型和大小组织地图、地形、天气、航海、知识、样式、字体、语音、缓存与个人数据。
- 停用地图时保留文件，但移出渲染和下一次共享索引范围。
- 提供批量校验/更新/启停/受保护删除及单地图详细动作。
- 可再生缓存单独计量并只允许清理白名单目录。
- 生命周期统一显示源时间、构建时间、上次检查和下次检查。
- 完整快照始终是灾备基线，增量 OSM 保持独立试验。

## 已实现行为与限制

Natural Earth 全球概览完全本地。定位未安装区域时，用户可以临时通过所选在线源查看当前视口，或进入精确离线包构建；在线浏览不会改变所有权状态。

每种资源都声明交付类型和可用维护动作。缺失的天气、航海、概览、百科和旅行资源显示真实安装动作；只有产品存在时图层才可用。库、样式、缓存与地图图层不会共用误导性的“下载”行为。

地图更新先刷新上游状态和源。共享中国快照的省份复用同一份新快照。成功后清单序列匹配上游并退出更新列表；重复更新被拒绝，“重建”保持独立。

TerraSys 不复制 OsmAnd 的移动导航客户端、服务权益或全球等高线分发。搜索与路线是共享派生索引，范围变化后要重建；地形只在本地 HGT 实际覆盖处提供；在线 OSM 只是当前视口参考，不是离线瓦片下载服务。

## 未直接采用的模式

- 移动底部抽屉、仅长按操作和应用商店购买状态不适合桌面本地系统。
- OsmAnd 专有服务与服务器下载限制不属于 TerraSys。
- 不复用单独受 CC BY-NC-ND 条款保护的 UI 资产和布局。
- TerraSys 保留桌面运维证据：来源哈希、构建日志、PostGIS 状态、容器健康和恢复包验证。
